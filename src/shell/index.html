How golem reads

A query, rung by rung

Each answer shows which rung read the query and what it was read as. Dashed slots are ambiguous readings: tap one to flip it and the answer recomputes. The line down the left of an answer has the rung's colour.

  1. context An open question from golem, or an amendment of the last answer: in feet, log scale, and chile, why, undo.
  2. grammar The controlled-English parse: the clause grammar of @gcu/dispatch, then rules for free text, dates and orientations.
  3. taught Phrases you taught on this device: dens means density.
  4. The dispatch CRF, for loose phrasing. Not wired yet.
  5. no reading It stops, shows the nearest skills, and offers to learn the word it did not know.

Open plan under an answer to see every step that produced it.

Sessions, history and names

A session is saved as its plan: the list of tool calls and their arguments. Opening one replays the plan, so history costs a few hundred bytes and old answers stay reproducible. The search box in the sidebar looks through every session.

Names are computed. Each answer contributes a label from its tool and subject, weighted by how much work the tool does: a table question outweighs a unit conversion. The name updates as the session grows and stops when you name it yourself: name this session friday lab run.

A session can be saved as a recipe and run again on other tables or columns: save this as a recipe called cu check, then run cu check for au.

Keys

  • Enter runs, Shift+Enter starts a new line, ↑ and ↓ on an empty line step through this session's queries.
  • / or Esc puts the cursor in the box.
  • Ctrl+Shift+O starts a new session, Ctrl+K searches every session (Enter opens the first), Ctrl+B shows or hides the sidebar. On a Mac, Cmd works for Ctrl.

Files

The paperclip opens tables (CSV, TSV, xlsx, Parquet, Datamine .dm), drawings and geometry (DXF, WKT, GeoJSON, YAML) and documents (Markdown, text, HTML). Files stay on this device. Documents are searched by word: find resurvey in my documents.

Hand-offs on Android

In the lead-acid shell, golem fills in an event, a timer or a message and hands it to the app you already use; that app asks you to confirm. Nothing goes through a Google API or the network. In a browser the hand-off is simulated.

What is real here

  • Computed in the page: units, arithmetic, dates, structure and the stereonet, tables and plots, conversions, document search, Python in a worker, all parsing, teaching and amendments.
  • Sample data is labelled as sample: assays.csv is synthetic, and the country figures are a rounded sample.
  • Out of scope by design: prose nobody authored a path to, such as essays, open translation, summaries in its own words and small talk. golem says it has no reading.
