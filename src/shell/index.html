How a query is read

Each card shows which rung read the query and what it was read as. Dashed slots are ambiguous readings: tap one to flip it and the answer recomputes.

  1. context An open question from golem, or an amendment of the last card: in feet, log scale, and chile, why, undo.
  2. grammar The controlled-English parse (clause). In this mock it is a rule table.
  3. taught Phrases you taught on this device: dens means density.
  4. The dispatch CRF, for loose phrasing. Not in this mock.
  5. no reading It stops, shows the nearest skills, and offers to learn the word it did not know.

Sessions, history and names

The menu button holds every session and a search across all of them. A session is saved as its plan: the list of tool calls and their arguments. Opening one replays the plan, so history costs a few hundred bytes and old answers stay reproducible.

Names are computed. Each card contributes a label from its tool and subject, weighted by how much work the tool does: a variogram outweighs a unit conversion. The name is the top one or two labels, prefixed with the table when one is open. It updates as the session grows and stops when you name it yourself: name this session friday lab run.

Calendar and other Android hand-offs

Adding to the calendar needs no Google API and no network. Android apps hand an event to whatever calendar app the user has, and that app syncs it through the user's own account.

The confirm-in-the-other-app route is the better default: golem fills the fields, the user presses save, and the app asks for no permissions. lead-acid's shim today has fetch, push streams, keep-awake, publish, share, attest and files. Hand-offs need one new native route that starts an intent from a small allowlist.

What is real in this mock

  • Computed in the page: units, arithmetic, dates, true thickness and the stereonet, the histogram, the Strunk check, all parsing, teaching and amendments.
  • Sample data: assays.csv is synthetic. The Factbook figures are a rounded 14-country sample. The ODS entry points to a section and does not show the passage.
  • Simulated: the device hand-offs. The timer counts down in the page.

Out of scope by design

Prose nobody authored a path to: essays, open translation, summaries in its own words, common-sense chat. golem says it has no reading. Everything else grows by adding tools and packs.
